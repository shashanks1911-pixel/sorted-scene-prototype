# Sorted Scene — interactive prototype

A static, mobile-first product demo for pub nights and trips. Open `index.html` or use the GitHub Pages URL.

All people, votes, venue notes and expenses are demonstration data. Changes stay in this browser’s local storage and are not shared between visitors. Switch demo identities to try guest and host actions. Reset clears this demo’s local state.

Includes voting, independent RSVP, host acceptance, final-plan confirmation, a Manali activity poll, equal expense splitting and two-sided simulated repayment confirmation. No real authentication, SMS, Google venue integration, bookings, uploads, or payment execution. The production application is maintained separately.
